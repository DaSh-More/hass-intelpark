# Дворецкий (Intelpark) для Home Assistant

[![HACS Custom](https://img.shields.io/badge/HACS-Custom-41BDF5.svg)](https://github.com/hacs/integration)
![Version](https://img.shields.io/badge/version-0.1.0-informational.svg)

Интеграция Home Assistant для сервиса **«Дворецкий»** (Intelpark): камеры и шлагбаумы вашего
двора прямо в Home Assistant — открывайте шлагбаумы и смотрите видео с камер, стройте
автоматизации и выводите всё на дашборд.

> ⚠️ Неофициальная интеграция, не связана с разработчиком сервиса «Дворецкий»/Intelpark.
> Используйте в рамках своего аккаунта; работоспособность может меняться при обновлениях сервиса.

## Возможности

- 🔐 **Авторизация по номеру телефона** через SMS-код — простой мастер настройки в интерфейсе.
- 🚧 **Шлагбаумы** — на каждый шлагбаум сущность `cover` с действием **«Открыть»**.
- 📹 **Камеры** — живой видеопоток и снимок для каждой камеры.
- 🧩 Камера и шлагбаум одного въезда объединены в **одно устройство**.
- 🔁 Повторная авторизация запрашивается автоматически, если сессия становится недействительной.

## Требования

- Home Assistant 2024.6 или новее.
- Действующий аккаунт «Дворецкий» с доступом к камерам/шлагбаумам и телефон для приёма SMS.

## Установка

### Через HACS (рекомендуется)

[![Открыть в вашем Home Assistant и добавить репозиторий в HACS.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=DaSh-More&repository=hass-intelpark&category=integration)

Нажмите кнопку выше — откроется ваш Home Assistant; подтвердите добавление репозитория,
затем установите **«Дворецкий (Intelpark)»** и перезапустите Home Assistant.

Или добавьте репозиторий вручную: HACS → Интеграции → меню ⋮ → **Пользовательские
репозитории**, добавьте `https://github.com/DaSh-More/hass-intelpark` (категория
**Integration**), затем установите **«Дворецкий (Intelpark)»** и перезапустите Home Assistant.

### Вручную

Скопируйте папку `custom_components/intelpark` в `config/custom_components/` вашего Home Assistant
и перезапустите его.

## Настройка

**Настройки → Устройства и службы → Добавить интеграцию → «Дворецкий»**. Введите номер телефона —
на него придёт SMS с кодом; введите код. После этого появятся устройства с камерами и шлагбаумами.

## Что появится

- `cover.*` — шлагбаумы; действие `cover.open_cover` открывает шлагбаум (из интерфейса,
  дашборда или автоматизации).
- `camera.*` — камеры с живым видео и снимком.

Сущности сгруппированы по въездам: у каждого шлагбаума — своё устройство с кнопкой открытия и
камерой.

## Известные ограничения

- Список камер и шлагбаумов формируется при загрузке интеграции. Если состав изменился на стороне
  сервиса — перезагрузите запись интеграции.
- Обратной связи о положении шлагбаума сервис не предоставляет, поэтому `cover` всегда в
  состоянии «закрыто», а доступно действие «Открыть» (открытие — разовый импульс).

## Планы

Отдельными релизами:

- **Сенсоры**: баланс объекта, пропуска, уведомления.
- **Сервисы**: выгрузка архивного видео, управление пропусками и уведомлениями.
