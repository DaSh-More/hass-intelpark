# brands-ассеты для интеграции `intelpark`

Логотип интеграции в HA (Настройки → Устройства и службы) берётся из репозитория
[home-assistant/brands](https://github.com/home-assistant/brands), локально не
подменяется. Чтобы логотип «Интеллект Парк» появился:

1. Форкнуть `home-assistant/brands`.
2. Скопировать эти файлы в `custom_integrations/intelpark/`:
   - `icon.png` — 256×256
   - `icon@2x.png` — 512×512
3. Открыть PR. После мерджа HACS/HA подтянут иконку по домену `intelpark`.

Источник: логотип 1024×1024, даунскейл LANCZOS. Требования brands: PNG, квадрат,
обрезанные поля. При желании можно добавить `logo.png`/`logo@2x.png` (горизонтальный
вариант) — прислать исходник в ширину ≥512.
